# SDG 3: Good Health & Well-Being Website

This project is a simple responsive website created for CDMU 2413 Assignment 2.  
It focuses on Sustainable Development Goal 3, which promotes good health and well-being for people of all ages.

## Project Features

- Multi-page website (Home, Gallery, About)
- Hero section with call-to-action
- JavaScript image carousel with:
  - Manual next and previous controls
  - Automatic slideshow
  - Infinite looping
  - Pause on hover
- jQuery smooth scrolling effect
- Responsive layout using HTML and CSS

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- jQuery

## Folder Structure

- index.html
- gallery.html
- about.html
- styles.css
- script.js
- img/
- Reflection_Report.pdf

## Purpose

The website aims to raise awareness about physical and mental health through clean design and interactive elements, while demonstrating fundamental front end web development skills.
